# Reference material

Use this directory for supporting documents consulted by the project, such as background research, external specifications, and source material. Link to material from the requirements, architecture, or decisions it informs, and record its source, version or date, and status when known.

Authoritative project requirements and architecture may live elsewhere in `docs/`. Agree which document is authoritative and link to it; do not treat a copied reference as an approved requirement or create competing sources of truth. Preserve existing files, respect access and licensing restrictions, and avoid storing secrets or sensitive data without authorized handling.
